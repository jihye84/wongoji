# 원고지 칠판

교실 칠판(TV·전자칠판)에 띄워 놓고 원고지 쓰기를 지도하는 웹앱이에요.

👉 https://jihye84.github.io/wongoji/

## 이런 걸 할 수 있어요

- 선생님 입력창에 글을 쓰면 원고지 칸에 원고지 사용 규칙대로 자동으로 들어가요.
  - 줄 끝 띄어쓰기는 칸 밖에 V표
  - 줄 첫머리에 올 문장 부호는 앞줄 칸 밖에
  - 숫자·영어 소문자는 한 칸에 두 자씩
  - 따옴표 자리, 마침표와 닫는 따옴표는 한 칸에
  - 물음표·느낌표·줄임표 다음 한 칸 띄우기
  - 마침표·쉼표 뒤 붙여 쓰기 / 띄어 쓰기 선택
- 원고지 줄 수 3~12줄 선택, 한 화면에 맞추기 / 칸 크기 고정(스크롤)
- 원고지 칸을 눌러 그 글자를 바로 고치기
- 예문 보기: 원고지 규칙이 모두 담긴 예문을 한 글자씩 써 보이기
- 인쇄: 가로폭 맞춤 / 한 장에 다 넣기, 가로·세로 용지, 따라 쓰기용 흐린 글씨
- 쓰던 글은 저절로 저장돼요
